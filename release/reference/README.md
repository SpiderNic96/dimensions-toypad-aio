Why it is not committed to ordinary Git history:

- the archive is ~246 MiB and contains a ~258 MB AppImage
- GitHub's normal repository file limits make a standard Git blob unsuitable
- a real GitHub publication should upload this ZIP as a GitHub Release asset, or use Git LFS with the corresponding LFS object
