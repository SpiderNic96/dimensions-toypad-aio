# Dimensions Toypad

LEGO Dimensions Toy Pad emulation for the Steam Deck, as a Decky Loader plugin,
with a bundled patched RPCS3.

- **Install:** `docs/INSTALL.md`
- **Changelog:** `docs/CHANGELOG.md`
- **Building / protocol reference:** `docs/BUILD.md`

## What it does

Emulates the LEGO Dimensions Toy Pad so figures can be placed, moved, swapped
and removed from a controller overlay in Game Mode, and renders the pad's live
LED state — solid colours, fades and flashes — as the game drives them.
